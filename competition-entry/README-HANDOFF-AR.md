# المرجع الأساسي وطريقة تشغيل النسخة الحالية

اعتمدت حزمة government-chatbot-codex-handoff.zip مرجع التنفيذ الأساسي. نسختها الأصلية كاملة في docs/handoff. ملف source/challenge_brief.pdf مطابق ببصمة SHA-256 للنسخة الرسمية السابقة. ترتيب المرجعية: قواعد PDF، ثم تحديد المستخدم لنموذج اللجنة، ثم متطلبات الحزمة. خطة التنفيذ اقتراح هندسي وليست قواعد إضافية من اللجنة.

الحزمة الأصلية تقول إن البيانات والنموذج غير مرفقين بها. في مشروعنا هما متوفران من المستخدم سابقًا: ملفات اللجنة الـ12 وcommand-r7b-arabic:7b. أمثلة docs/handoff/examples مصطنعة لشكل البيانات، ولا تدخل في الإجابة. النص المستخرج للـPDF مساعد فقط.

## التشغيل

Python الذي اختبرناه محليًا: 3.14، والمشروع يستعمل المكتبة القياسية فقط. لا يعتمد المسار على Next.js أو npm أو المتصفح، ولا ينزّل شيئًا وقت التشغيل. requirements.txt يعلن عدم وجود حزم pip مطلوبة. على جهاز جديد جهّز Python وOllama والنموذج قبل فصل الإنترنت.

من مجلد competition-entry في PowerShell:

```powershell
$env:OLLAMA_MODEL='command-r7b-arabic:7b'
python doctor.py
python main.py questions.json
python verify_submission.py questions.json answers.json
python -m unittest discover -v
```

أو `./run.ps1` بعد ضبط المتغير. الملف المحلي .env يحفظ اختيار المستخدم الحالي؛ له نموذج مشاركة .env.example بقيمة placeholder. متغير OLLAMA_MODEL صريح وإلزامي في البيئة أو .env، ولا يوجد اختيار تلقائي أو نموذج احتياطي. لا يعتمد المسار بعد الآن على COMPETITION_MODEL.

على Unix:

```sh
export OLLAMA_MODEL='command-r7b-arabic:7b'
python3 doctor.py
python3 main.py questions.json
python3 verify_submission.py questions.json answers.json
```

يمكن تمرير مسار أسئلة من مجلد آخر. الناتج دائمًا بجوار main.py. يمنع إدخال answers.json نفسه أو ملف مرتبط به كملف أسئلة. يحتفظ البرنامج بأي metadata، ويعالج المحادثات الفارغة، ويكتب checkpoints ذريًا. أخطاء إعداد صالحة الإدخال تنتج error صريحًا لكل رسالة وخروجًا غير صفري. المدخل JSON غير الصالح يرفض قبل لمس ملف الناتج.

## الوحدات

| الملف | الوظيفة |
|---|---|
| main.py | التوليد المحلي، التسلسل، الحفظ والتعامل مع أخطاء الرسائل |
| config.py | إعداد صريح، loopback فقط، سياق ومهلة ومخرجات قابلة للضبط، UTF-8 للطرفية |
| corpus.py | الجرد، بصمات البايتات، الحقول التسعة، المقاطع والأسطر الأصلية |
| routing.py | توجيه محافظ بلا رسوم أو أجوبة ثابتة؛ حدود كلمات ومقارنات ومتابعة |
| grounding.py | تحقق معرفات وأرقام عربية/فارسية/مكتوبة بالكلمات ومخرجات مشوهة |
| fee_rules.py | تحليل شروط فروع من النص، وفصل الرسم الأساسي والإضافي عندما تُثبت الحالة البسيطة؛ لا مبالغ خدمة ثابتة |
| dialogue.py | تاريخ محدود مع مرجع الخدمة الأخير؛ لا اقتطاع صامت للدور الكبير |
| contract.py | فحص المدخلات، حفظ metadata، منع التصادم والكتابة الذرية |
| doctor.py | فحص corpus والنموذج المثبت محليًا دون سحب أو توليد |
| verify_submission.py | فحص البنية والسياقات؛ لا يمنح شهادة دقة معنوية |
| tests/ | fixtures مصطنعة معزولة واختبارات بيانات رسمية موسومة بوضوح |

التطبيع للبحث فقط؛ لا تعاد صياغة مصدر الأدلة. يتكرر عنوان الخدمة الأصلي فوق حقلها لتمييز الخدمات المتشابهة، ويبقى جسم الحقل كما ورد. source_sha256 وchar_start/end وline_start/end تحفظ للتتبع، ولا تُضاف إلى نص contexts. فهرسة البنية خفيفة ولا تحتاج Vector DB أو نموذج تضمين في مسار المسابقة.

## الضبط والتشخيص

OLLAMA_CONTEXT_SIZE وOLLAMA_OUTPUT_TOKENS وOLLAMA_TIMEOUT_SECONDS وOLLAMA_MAX_PROMPT_CHARS قابلة للضبط ضمن حدود معلنة. ميزانية الحروف محافظة وليست tokenizer؛ يتوقف الطلب الكبير بدل قص الأدلة بصمت. تفحص metadata عند اقتراب السياق من سعته أو بلوغ حد المخرجات؛ غياب بيانات كافية لا يثبت عدم الاقتطاع. إصلاح الصيغة/الأدلة محدود بمرة واحدة، وتكرار فشل الاتصال يفتح circuit breaker بدل استنزاف مهلة لكل الرسائل.

run-report.json يسجل أزمنة وعدد نداءات وإعدادات الجهاز وبصمات المصدر. OLLAMA_TRACE=false افتراضيًا؛ تفعيلها يحفظ نصوص توليد حساسة محليًا فقط. لا يوجد cache نهائي للإجابات ولا lookup للإجابات المرجعية. recheck.py وevaluate_cases.py أدوات تطوير منفصلة، ولا يقرأهما main.py لتحديد الأجوبة.

## حدود الفحص

فحص الأرقام ضروري لكنه لا يثبت انطباق الفرع؛ الأرقام الموجودة بالسؤال أو المصدر قد تستخدم باستنتاج خاطئ. الأرقام المكتوبة بالكلمات لها مقابلات لغوية محدودة. لا يسمح بمجموع غير صريح إلا لجمع فريد مثبت المكونات وبمصادرها، مع ذكر الأساسي والإضافي عند طلبهما. لا تزال مراجعة بشرية مطلوبة للشروط والنفي والادعاءات غير الرقمية والسياقات الزائدة.

جدول PASS/PARTIAL/BLOCKED واختبارات هذه النسخة في HANDOFF-ACCEPTANCE-AR.md. تقرير RUN-RESULTS-AR.md يوثق جولة سابقة ويظل تاريخيًا؛ لا تُنسب أزمنته تلقائيًا لهذه النسخة. الخطوة الفيزيائية لإطفاء Wi-Fi واختبارات اللجنة الخفية لم تُنجز.
